MotifJS tarayıcı benchmark düzeneği

js-framework-benchmark senaryoları: 1k/10k satır oluştur, 1.000 satır ekle, her 10. satırı güncelle, satır değiştir (swap), satır seç, satır sil, temizle. Ölçüm: işlem başlangıcından çift requestAnimationFrame (boyama) sonrasına kadar. Production dist/index.umd.min.js'e karşı çalışır; önce npm run build --workspace=@motifx/core. Tablo, satırlar, hücreler, bağlantılar ve metinlerin hepsi MotifJS bileşenidir; kod derleyicinin JSX'ten ürettiği biçimdedir.
